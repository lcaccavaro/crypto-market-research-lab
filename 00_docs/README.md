# Documentação — Market Research Lab

> Esta pasta contém toda a documentação do projeto: princípios, protocolos, glossário e registros de hipóteses.

## Arquivos

| Arquivo | Descrição | Quando usar |
|---|---|---|
| [glossary.md](glossary.md) | Glossário técnico com 33 termos | Ao encontrar um termo desconhecido |
| [research_principles.md](research_principles.md) | Princípios científicos invioláveis | Antes de qualquer análise |
| [experiment_protocol.md](experiment_protocol.md) | Template de protocolo para hipóteses | Ao iniciar uma nova hipótese |
| [hypotheses.md](hypotheses.md) | Registro de todas as hipóteses | Para acompanhar o status de cada H |
| [data_sources.md](data_sources.md) | Catálogo de fontes de dados | Ao buscar dados para uma análise |
| [repositories.md](repositories.md) | Repositórios e referências externas | Ao buscar referências de código/paper |

## Fluxo de trabalho

```
1. Leia research_principles.md          → entenda as regras
2. Registre a hipótese em hypotheses.md → antes de qualquer análise
3. Preencha o protocolo completo        → usando experiment_protocol.md
4. Identifique as fontes de dados       → usando data_sources.md
5. Execute a análise                    → nos notebooks de 03_notebooks/
6. Registre o resultado                 → em hypotheses.md e no protocolo
```
